# CUTLINE

Онлайн-игра на ставки. Поле делится на территории по размеру ставок, нож режет поле, пока не останется одна территория — её владелец забирает пул.

Два режима:

- **PvP** — настоящие Gram (TON). Пополнение переводом на кошелёк игры без комментария: игрок получает точную сумму с уникальными последними цифрами (например, 10.004371), по ней сервер и узнаёт перевод. Вывод по заявке.
- **ForFun** — тестовый баланс для веселья: старт 10, «+» раз в раунд даёт 10–100.

Интерфейс на английском, русский включается в профиле (шестерёнка → язык).

## Как устроено

- `index.html` — клиент (одна страница, без сборки).
- `core.js` — общая детерминированная логика: раскладка поля, модификаторы, симуляция разрезов. Один и тот же файл работает в браузере и на сервере.
- `supabase/migrations/001_init.sql` — таблицы, RLS и серверные функции.
- `supabase/functions/game/` — edge-функция: вход через Telegram, расчёт раунда, тестовое меню.
- `brand/` — иконки.
- `tonconnect-manifest.json` — манифест TON Connect для оплаты кошельком.
- `supabase/migrations/006_invoices.sql` — пополнение без комментария по точной сумме.
- `supabase/migrations/005_real_money.sql` — реальные балансы, журнал, пополнения, выводы, комнаты PvP/ForFun.

## Безопасность

- Играть можно только из Telegram Mini App бота @cutline_game. Сервер проверяет подпись Telegram токеном бота; один Telegram-аккаунт — один игровой аккаунт. Имя и аватарку записывает сервер, клиент изменить их не может.

- Баланс и ставки меняются только серверными функциями (`place_bet`, `claim_faucet`, `settle_round`). У клиента нет прав на запись в таблицы.
- Результат раунда считает сервер. Хэш сида публикуется до ставок, сам сид раскрывается после раунда. Любой раунд можно проверить в «Истории».
- Реальный баланс меняется только через `private.real_change`, каждая операция пишется в журнал (`private.ledger`) с остатком после неё.
- Пополнение: сервер читает входящие переводы на кошелёк игры (toncenter) и подтверждает каждый во втором индексаторе (tonapi): адрес, отправитель, сумма, lt, комментарий и успешность должны совпасть. Один хеш транзакции зачисляется один раз. Перевод узнаётся по точной сумме из открытого счёта (одна и та же сумма не выдаётся повторно 48 часов, перевод должен прийти, пока счёт открыт) или по личному коду в комментарии, который TON Connect добавляет сам. Остальные переводы сохраняются как «без кода» и разбираются поддержкой.
- Вывод — заявка. Перед ней сервер сверяет баланс с пополнениями, ставками, выигрышами, выводами и возвратами и проверяет непрерывность журнала. Если хоть что-то не сходится, заявка сохраняется со статусом «на проверке», деньги не списываются, игрока просят написать в поддержку. Выплаты делает владелец вручную из админ-панели (с перепроверкой пополнений в блокчейне), ключи кошелька на сервере не хранятся.
- ForFun: бесплатное пополнение случайно от 10 до 100, раз в раунд, только тестовыми деньгами. Тестовые инструменты (боты, выбор модификатора) работают только в ForFun.
- Комиссия «дома» (только PvP): 2% с банка (минимум 0.1). Если так победитель остался бы ниже своей ставки + 0.1, берётся 2% от выигрыша у других, и комиссия никогда не больше выигрыша − 0.1: победитель всегда в плюсе. Правило каждого раунда записано в `rounds.fee_rule` и проверяется в «Истории».

## Запуск

Игра выложена на GitHub Pages и открывается как Mini App бота @cutline_game. Вне Telegram показывается экран со ссылкой на бота. Адрес Supabase и публичный anon-ключ уже прописаны в `index.html`; anon-ключ публичный по задумке, все права ограничены RLS.

## Обновления

При каждой выкладке поднимите версию в `version.json` и `BUILD` в `index.html`: открытые игры заметят её и перезагрузятся между раундами.

## Деплой бэкенда в свой проект

```bash
supabase db push                       # применит миграцию
supabase functions deploy game --no-verify-jwt
supabase secrets set TELEGRAM_BOT_TOKEN=...   # токен бота, только на сервере
```

Админ-код для тестового меню хранится только как SHA-256 в `private.admin_config` и в репозиторий не попадает:

```sql
insert into private.admin_config(key, value)
values ('code_hash', encode(extensions.digest('ваш-код', 'sha256'), 'hex'));
```
